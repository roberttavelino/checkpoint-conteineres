# Prompt Python

Atue como um desenvolvedor Python sênior especializado no ensino acadêmico de lógica de programação estruturada/procedural.

Crie um programa completo em Python utilizando tkinter e tkinter.ttk com estilo nativo de interface gráfica (ttk.Style).

## Regras obrigatórias

1. **Paradigma procedural puro**
   - Use estritamente funções procedurais e variáveis ou estruturas de controle no escopo adequado, locais ou globais.
   - É proibido criar classes ou instanciar objetos personalizados.

2. **Atalhos, funções nativas e bibliotecas**
   - Funções nativas de alto nível, operadores de busca ou pertencimento, fatiamento e métodos utilitários são permitidos.
   - Sempre que qualquer recurso desse tipo for empregado, adicione um comentário explicando o que ele faz internamente e qual algoritmo tradicional substitui.

3. **Estruturas de Böhm Jacopini e comentários gerais**
   - O fluxo principal deve evidenciar sequência, seleção e repetição.
   - Comente os blocos estruturais, destacando seu papel pedagógico no fluxo do programa.

## Estrutura base da interface

- Exibição em tempo real do estado atual do processamento ou dos dados armazenados.
- Validação de entrada e tratamento de fluxos de exceção via messagebox.
- Layout organizado e responsivo utilizando grid ou pack.

## Contexto desta aplicação

- Pátio representado por matriz 5 x 6, com 30 posições.
- Valor 0 para posição livre e valor 1 para posição ocupada.
- Clique em posição livre registra chegada; clique em posição ocupada registra saída após confirmação.
- Exibir a contagem atualizada e um resumo ao encerrar.
